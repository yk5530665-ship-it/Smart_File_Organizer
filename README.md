# 📁 Smart File Organizer

A Python automation tool that automatically organizes files
into folders based on their file extensions.

## 🚀 Features

- Automatically detects file types
- Creates folders automatically
- Organizes images, videos, documents, audio, archives and code
- Handles unknown file types
- Prevents duplicate files from being overwritten
- Maintains an activity log
- Uses Python file-handling and automation concepts

## 🛠️ Technologies

- Python
- pathlib
- shutil
- logging

## 📂 Supported Categories

| Category | Extensions |
|----------|------------|
| Images | JPG, JPEG, PNG, GIF, WEBP, SVG |
| Videos | MP4, MKV, MOV, AVI, WEBM |
| Documents | PDF, DOC, DOCX, TXT, PPT, XLS, CSV |
| Audio | MP3, WAV, AAC, FLAC, M4A |
| Archives | ZIP, RAR, 7Z, TAR, GZ |
| Code | PY, JAVA, CPP, C, JS, HTML, CSS, SQL |
| Others | Unknown file types |
